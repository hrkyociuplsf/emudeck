## Overview

EmuDeck installs and configures a curated suite of emulators on Steam Deck and Linux desktop, setting up RetroArch, RPCS3, Yuzu, and others with optimal defaults, shader packs, and Steam ROM Manager.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **EmuDeck** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **One-Click Setup** | Install and configure 30+ emulators with a single setup wizard |
| **Steam Integration** | Adds ROM shortcuts to Steam library with artwork and metadata |
| **Cloud Saves** | Sync save states and battery saves to cloud storage automatically |
| **Shader Packs** | Pre-configured CRT and upscaling shader presets for each platform |
